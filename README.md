## 现在能玩什么（Phase 2）

打开场景 **`Assets/Scenes/Boot.unity`**：

- 季节（春夏秋冬，90 日/季）进入模拟公式
- 数据驱动资源（粮食易腐 / Mana 持久）
- 正式事件状态 + 地图色点
- 人口采样点密度（非 NPC）
- **+1年/+10年数学快进**（非逐日循环）
- HUD「一致性测试 1年」
