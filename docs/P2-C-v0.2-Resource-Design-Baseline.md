# P2-C v0.2 资源设计基线

本轮**只记录**，**不接入**外交公式。  
禁止：资源 → 外交关系。  
禁止：木材 / 矿物 / 魔力 / 粮食 / 水 贸易。  
资源贸易留到后续阶段。代码记录见 `ResourceDiplomacyBaseline`（`CoupledToDiplomacy = false`）。

## 水

- 生存资源
- 影响粮食生产
- 影响承载力

## 粮食

- 人口生存
- 出生 / 人口系统相关
- 疾病 / 稳定相关

## 信仰

- 玩家等级
- 玩家权限
- 信仰强度与人口总数、物资表现等相关
- 本轮不要重新实现信仰公式

## 木材

- 自然产出
- 年度产出存在上限
- 日常消耗
- 战备时消耗增加

## 矿物

- 日常消耗
- 科技发展
- 战备时消耗增加

## 魔力

- 魔法发展
- 战备时消耗增加

## 知识 / 教育

- 当前已有发展系统
- 本轮不修改现有公式
